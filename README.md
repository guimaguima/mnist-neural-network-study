# MNIST Neural Network Study
Welcome! This repository explores different approaches to the MNIST dataset through self-guided studies, using data flattened vector data from CSV files or imported into PyTorch.

## Scratch vs. Torch
### Scratch 🌟
The Scratch implementation is part of the learning process for beginners, ideal for understanding the fundamentals of how neural networks (e.g., deep learning) work.
This section is built using *pure linear algebra, Python, and NumPy*, with no high-level frameworks.

### PyTorch🔥
The PyTorch section uses the PyTorch library, focusing on higher-level abstractions essential for building efficient models. This part is split into two approaches:

Linear Models: Basic neural networks using *PyTorch's linear algebra* capabilities.

Convolutional Models: Advanced architectures leveraging *convolutional layers* for improved performance.

## How to Run?🏃
### 1. Clone the Repository
```cmd
    git clone https://github.com/guimaguima/mnist-neural-network-study.git
```
### 2. Install Requirements
Navigate to the root folder and run:
```cmd
    pip install -r requirements.txt
```

### 3. Run Code & Notebooks
Scripts: Execute the Python scripts directly in your environment❗
Notebooks: Open Jupyter Notebook/Lab to run the notebooks. All models are lightweight and should run on most machines.
(Ensure Jupyter is installed via pip install jupyter if not already present.)
